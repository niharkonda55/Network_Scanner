Network Traffic Monitoring and Phishing Detection Tool

This project is a full-stack, web-based cybersecurity dashboard designed for real-time network monitoring, phishing detection, and offline packet (.pcap) analysis. Built with a focus on usability, performance, and security, the tool empowers both technical and non-technical users to visualize network activity, detect anomalies, and investigate suspicious traffic from a unified interface.

The application provides:

Live network traffic monitoring with protocol breakdown, connection visualization, and suspicious-activity alerts.

Capable of identifying malicious URLs, packets, and request patterns.

Offline PCAP analysis, enabling users to upload packet-capture files and receive automated threat insights.

Interactive dashboards and logs, allowing users to explore traffic in depth, track trends, and export findings.

Lightweight and efficient, this tool is ideal for cybersecurity learners, researchers, home-lab users, and analysts looking for a centralized platform to monitor network security and detect potential threats in real time.
